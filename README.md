# Мой день — мобильная PWA-версия

Тёмный сине-прозрачный планировщик: задачи, цели, привычки, статистика и Pomodoro.

## На телефоне
1. Открой сайт через HTTPS-хостинг.
2. iPhone: Safari → Поделиться → «На экран Домой».
3. Android: Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Данные сохраняются локально в браузере. Для общей синхронизации между телефоном и ПК нужен облачный backend (например, Supabase/Firebase).
